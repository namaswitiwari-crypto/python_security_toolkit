\# Python Security Toolkit



\## Integrated Ethical Hacking Framework



A modular Python-based cybersecurity toolkit that combines multiple security-testing and network-monitoring demonstrations into a single command-line application.



> \*\*Responsible Use:\*\* This project is intended only for ethical hacking education and authorized security testing. Use the toolkit only on systems, networks, virtual machines, or devices for which you have explicit permission.



\---



\## Project Overview



The Python Security Toolkit integrates the security-testing concepts taught during the Python for Ethical Hacking bootcamp into one organized application.



The project provides a common menu-driven interface through which users can select individual modules and provide the required inputs.



\## Features



The toolkit currently contains the following modules:



1\. MAC Changer

2\. Network Scanner

3\. ARP Spoofer Demonstration

4\. Packet Sniffer

5\. Network Jammer Demonstration

6\. DNS Spoofer Demonstration

7\. ARP Spoof Detector
